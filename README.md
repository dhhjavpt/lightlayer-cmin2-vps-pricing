## “三网优化”到底优化了谁

LightLayer 的“三网优化”在 2024 年洛杉矶测评里，指的是去程三网直连美国西海岸、回程统一走移动 CMIN2/AS58807，不是三家运营商各走各的精品线。这个区别直接决定它适不适合你。

| 线路 | 主要优化谁 | 特点 |
| --- | --- | --- |
| 电信 CN2 GIA（AS4807） | 电信 | 延迟低、晚高峰稳，价格通常最高 |
| 联通 AS9929 / CUII | 联通 | 联通高端线路，非高峰丢包控制较好 |
| 移动 CMIN2（AS58807） | 移动 | 移动高端线路，比早期 CMI 稳定 |

移动用户走 CMIN2 回程是顺路，晚高峰体验通常比普通 BGP 好。电信用户走 CMIN2 回程，就不如专门走 CN2 GIA 的套餐针对性强；联通用户同理，AS9929 才是联通的主场。

2026 双11 的圣何塞款官方只写“1Gbps 优化”，没有公开逐运营商回程。买之前最好用测试 IP 或工单问清：电信、联通、移动分别走什么回程。如果回答不了，就按“移动优先、电信联通谨慎”来判断。

## 便宜背后的真实成本：1Gbps 不等于无限流量

圣何塞 $4.95 的 1Gbps 是峰值带宽，月流量只有 1TB；洛杉矶 $4 的 20M 不限流，峰值低，但一个月跑满理论约 6.4TB。两个价格差不多，用法完全相反。

1TB 流量在 1Gbps 下理论全速约 2.3 小时跑完，在 50Mbps 下约 45 小时跑完。20M 不限流跑满一个月，理论约 6.4TB；30M 不限流理论约 9.7TB。这些都是峰值理论值，实际受线路、磁盘和站点负载影响，但足够说明一件事：**带宽数字大，不代表每月能跑的数据多。**

所以 2G 不限流 30M 和 2G 1TB 50M 都卖 $5.6 时，选择标准很简单：

- 流量平稳、长期挂机、不想每月算额度：选 30M 不限流。
- 平时流量小，偶尔要短时间拉满 50M：选 1TB 限量款，但别把它当大流量套餐用。

**美国、新加坡、香港怎么选？**
